# 更新紀錄

## 1.2.3

- 相容性上限由 4.2.99 改為 4.99，並加入 `supportsQt6=True`，可安裝於 QGIS 4.4 及後續 4.x 版本。
- 圖示由 PNG 改為 SVG（`icon.svg`），保留原雙綠雲朵、循環箭頭與圖層設計。
- 測試程式改用 Qt6 相容的完整列舉名稱。
- 加入「本外掛透過 Claude Code 製作」聲明。
- 功能與運作方式與 1.2.2 相同。
- Windows 11／QGIS 4.4.0（Qt 6.11.3、Python 3.12）：維護者安裝並測試可正常使用。

## 1.2.2

- 改用雙綠配色、雲朵與圖層更新圖示。
- 名稱改為「NLMA都市計畫/國家公園使用分區圖連線」，作者為 Xing Li。
- 補齊聯絡信箱、原始碼網址及 GPL-2.0-or-later 授權。
- 專案讀取時取消舊請求，避免套用過期回應。
- 健康檢查收到 HTTP 401、403、498、499 時嘗試更新連線。
- 拒絕非有限圖磚原點與非整數縮放級別。
- 開放安裝至 QGIS 4.2.x，取消實驗性標記。
- QGIS 3.40.6：7 項自動測試通過；QGIS 4.2.3：使用者回報可用。

## 1.2.1

- 本次修改所依據的既有版本；支援都市計畫及國家公園使用分區連線。
