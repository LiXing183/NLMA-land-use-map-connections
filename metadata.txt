about=Adds Taiwan National Land Management Agency urban planning and national park land-use zoning XYZ layers. Checks connections every five minutes and refreshes service tokens when needed. Existing layers are retained when service validation fails. Internet access is required. This is an independently developed plugin, not an official NLMA product.
    Version 1.2.3 widens the declared compatibility to all QGIS 4.x releases (qgisMaximumVersion=4.99, supportsQt6=True) so the plugin can be installed on QGIS 4.4 and later; runtime behaviour is unchanged from 1.2.2. The maintainer installed and tested 1.2.3 on Windows 11 with QGIS 4.4.0 (Qt 6.11.3, Python 3.12); other declared versions and operating systems have not been separately validated.
    1.2.3 將宣告支援範圍擴大至所有 QGIS 4.x，功能與 1.2.2 相同。維護者已於 Windows 11／QGIS 4.4.0（Qt 6.11.3、Python 3.12）安裝並測試 1.2.3；其他宣告支援版本及作業系統未逐一驗證。
